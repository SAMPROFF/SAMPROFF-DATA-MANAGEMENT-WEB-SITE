# SAMPROFF-DATA-MANAGEMENT-WEB-SITE

This web site is a data driven site that manages all kinds of data, analyses them, and gives institutions or companies a comprehensive indexed report across many sectors. Example sectors include farming, herbal, mining, health, media, mobile, marketing, and more.

## Live Websites

- BNS-SAMPROFF LTD Company Website: https://bns-samproff-co-ltd.netlify.app
- Number Five Herbal Clinic Website: https://number-five-herbal-clinic.netlify.app

## Herbal Partner

Number Five Herbal Clinic is now listed on the BNS-SAMPROFF website as the herbal partner. Visitors can click the Herbal Partner section on the BNS-SAMPROFF website to open the Number Five Herbal Clinic website directly.

## Focus Areas

- Data collection and organization
- Data cleaning, analysis, visualization, and reporting
- Agricultural and local medicine information management
- Herbal sector data support
- Partnership documentation for donors, investors, clinics, and researchers
